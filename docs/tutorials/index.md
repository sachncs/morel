# Tutorials

morel's tutorials walk you through the package end-to-end, in the order
in which most people actually use it. Each is a self-contained guide
with runnable code.

## Reading order

If you are new to the project, work through them in this order. Each
later tutorial assumes the previous one is familiar. If you only care
about one of the three flows, jump straight to it.
