# Citation

If morel contributes to your research, cite the project using the metadata in
[`CITATION.cff`](https://github.com/sachncs/morel/blob/master/CITATION.cff):

```bibtex
@software{morel,
  author  = {Sachin},
  title   = {morel},
  url     = {https://github.com/sachncs/morel},
  license = {MIT}
}
```

The repository remains the canonical source for machine-readable citation
metadata; this page keeps the citation entry discoverable inside the docs.
