# Code of Conduct

## Our standard

We want morel to be a welcoming, constructive project for people with
different backgrounds and levels of experience. Participate with respect,
assume good intent, and focus criticism on ideas and implementation rather
than people.

Unacceptable behaviour includes harassment, discrimination, personal attacks,
deliberate disruption, and publishing private information without permission.

## Project spaces

Maintainers may remove comments, close discussions, or limit participation
when behaviour conflicts with this standard. They will aim to explain the
decision clearly and apply it consistently.

## Reporting

For sensitive concerns, contact the maintainers privately through the security
contact listed on the [Security page](security.md). For ordinary project
questions, use [GitHub Discussions](https://github.com/sachncs/morel/discussions).
