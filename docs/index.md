# Documentation

This is the working reference for morel: install it, run a deterministic
pipeline, inspect the implementation, and operate the service safely.

## Start with the task in front of you

- **New to morel?** Follow [Getting started](getting-started.md).
- **Trying to reproduce a result?** Use the [reproduction workflow](operations/reproduce.md).
- **Adding a component?** Read [custom components](howto/custom-component.md).
- **Deploying the service?** Follow [deployment](operations/deploy.md) and the
  [observability](operations/observability.md) guide.
- **Looking for a symbol?** Open the [API reference](reference/api.md).
